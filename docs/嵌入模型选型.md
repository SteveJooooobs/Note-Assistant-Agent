# 嵌入模型选型

## 项目背景

- 笔记助手 Agent，个人知识库
- 笔记为中文 Markdown 文件
- 初期约 18 个文件、几百个 chunk，后续每 1-2 周增量更新

## 选型标准

按优先级排序：

1. **中文语义对齐** — 参考 C-MTEB（中文版 MTEB）榜单，不看英文 benchmark
2. **性价比** — 小规模知识库用小模型就够了，大模型收益递减
3. **向量维度** — 维度越高存储越大、检索越慢，但对小规模影响不大
4. **加载便利性** — 本地用 `sentence-transformers` 加载，无需额外服务

## 候选模型对比

| 模型 | 维度 | 大小 | 中文质量 | 适合场景 |
|---|---|---|---|---|
| `BAAI/bge-small-zh-v1.5` | 512 | ~100MB | ★★★☆ | 资源受限、快速原型 |
| `BAAI/bge-base-zh-v1.5` | 768 | ~400MB | ★★★★ | **性价比最优** |
| `BAAI/bge-large-zh-v1.5` | 1024 | ~1.3GB | ★★★★★ | 追求极致、大规模库 |
| `moka-ai/m3e-base` | 768 | ~400MB | ★★★★ | bge 的备选 |

## 最终选择

**`BAAI/bge-base-zh-v1.5`**

### 选择理由

1. BGE 系列在 C-MTEB 中文榜单上综合表现最好
2. `base` 比 `small` 只大约 300MB，但检索质量明显高一个档次
3. 比 `large` 轻量得多，首次下载快、推理快
4. 768 维是 ChromaDB 的甜点区
5. 从课程学习角度，`base` 是更标准的选择，学完以后换项目也能直接用

### 使用方式

```python
# config.py
EMBEDDING_MODEL = "BAAI/bge-base-zh-v1.5"
EMBEDDING_CACHE_DIR = "./models"  # 本地缓存目录，首次下载后复用

# rag.py 中加载
from langchain_huggingface import HuggingFaceEmbeddings
embeddings = HuggingFaceEmbeddings(
    model_name=EMBEDDING_MODEL,
    cache_folder=EMBEDDING_CACHE_DIR,  # 首次下载到 ./models，后续本地加载
    model_kwargs={"device": "cpu"},    # 无 GPU 用 cpu，有则换 cuda
)
```

首次运行时 `HuggingFaceEmbeddings` 会自动从 HuggingFace Hub 下载模型到 `./models/` 目录，后续启动直接从本地加载，无需联网。

### 依赖

```bash
pip install langchain-huggingface sentence-transformers
```

## 注意事项

- 模型一经选定不要轻易更换——换模型意味着向量空间变了，所有已入库 chunk 需要全量重建
- 此选型在几千个文件的规模下依然是合理的，无需升级到 `large`
