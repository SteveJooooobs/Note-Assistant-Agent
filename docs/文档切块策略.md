# 文档切块策略

## 背景

笔记格式严格，结构如下：

```
# 文档标题（h1）
---
## 1. 知识点A（h2）
### 概念详解（h3）
### 知识点关联（h3）
### 工业级应用举例（h3）
---
## 2. 知识点B（h2）
### 概念详解
### 知识点关联
### 工业级应用举例
---
```

每个 `##` 是一个完整、自洽的知识单元。使用固定 `chunk_size` 切块会破坏语义完整性。

## 问题分析

| 方案 | 问题 |
|---|---|
| 纯固定大小切（`RecursiveCharacterTextSplitter`） | 知识点被切成两半，检索语义跑偏 |
| 纯标题切（`MarkdownHeaderTextSplitter`） | 不保证长度，超长 chunk 超出 embedding 上下文窗口 |

## 最终方案：标题切块为主 + 字符切块兜底

两步走：

1. **`MarkdownHeaderTextSplitter`** 按 `##` 标题切出语义块
2. **`RecursiveCharacterTextSplitter`** 对超长块按中文句子边界二次切分

```python
from langchain_text_splitters import MarkdownHeaderTextSplitter, RecursiveCharacterTextSplitter

# 第一步：按标题切出语义块
md_splitter = MarkdownHeaderTextSplitter(
    headers_to_split_on=[("##", "section")],
    strip_headers=False,  # 保留标题文本
)
md_splits = md_splitter.split_text(markdown_text)

# 第二步：对过长的块用字符级切分器二次切分
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=800,
    chunk_overlap=150,
    separators=["\n\n", "\n", "。", "，", " ", ""],  # 中文友好分隔符
)
final_chunks = text_splitter.split_documents(md_splits)
```

## 效果

- 90% 的知识点完整保留在同一个 chunk 中
- 少数超长内容按句号/逗号边界二次切分，保持子句完整
- 检索结果是一个完整的知识单元，而非半截段落

## 中文分词特殊处理

分隔符列表中 `"。", "，"` 放在 `"\n"` 之后、空格之前，确保：
- 优先按段落边界切（`\n\n`、`\n`）
- 其次按句子边界切（`。`、`，`）
- 最后才到空格和字符级别
