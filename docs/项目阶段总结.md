# 项目阶段总结（Week 9 Demo — 笔记助手 Agent）

## 当前状态：MVP 跑通 ✅

全链路可运行：加载笔记 → 切块 → Embedding → ChromaDB → ReAct Agent → CLI 交互。

## 技术栈

| 层 | 选型 |
|---|---|
| LLM | ChatOpenAI → DeepSeek API（`deepseek-v4-flash`） |
| Embedding | `BAAI/bge-base-zh-v1.5`，本地加载（魔搭下载，`./models/`） |
| 向量库 | ChromaDB 持久化（`./chroma_db/`） |
| Agent | `langchain.agents.create_agent`（ReAct 范式） |
| 切块 | MarkdownHeaderTextSplitter（`##` 标题切） + RecursiveCharacterTextSplitter（兜底） |

## 项目结构

## 已完成的模块

### rag.py — RAG 管道

- `build_index(chunks, persist_dir)`：全量建库，目录已存在则跳过
- `update_index(docs_dir, persist_dir, index_record_path)`：增量更新，基于 `indexed_files.json` 做新增/修改/删除三类变更检测
- `retrieve(vectorstore, query, k)`：语义检索
- 切块策略：`##` 标题切语义块 → `RecursiveCharacterTextSplitter`（中文分隔符）兜底
- metadata 保留 `source` 和 `mtime`，增量更新依赖

### tools.py — 工具

- `get_tools(vectorstore)` 工厂函数，闭包注入向量库
- `search_notes`：语义检索，返回格式化结果（含来源文件）
- `create_note`：新建 Markdown 笔记，文件名清洗
- `create_folder`：新建子文件夹

### agent.py — Agent

- `set_agent(tools)` 创建 ReAct Agent
- 6 条 system_prompt 行为规则：先检索再回答、引用来源、无结果坦诚告知

### main.py — CLI

- 加载已有 ChromaDB → 获取工具 → 创建 Agent → 交互循环
- `stream` 输出，按消息类型（AI/工具调用/工具结果）解析显示
